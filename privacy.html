Privacy policy

Effective October 25, 2026

Watson is a private assistant used only by the members of one household. It is not offered to the public.

What Watson accesses

With each person's permission, Watson reads and changes events on that person's Google Calendar and on calendars they share, using Google's calendar.events permission. It does not access email, contacts, files or any other Google data.

How the data is used

Calendar data is used only to answer the household's own requests, such as listing, adding or moving events. Changing or deleting an event always requires the person's confirmation first.

Storage and sharing

Data is processed on a server controlled by the household. Requests are processed by Anthropic's Claude API to understand what was asked. Calendar data is never sold, never used for advertising, and never shared with anyone else.

Google API Services User Data Policy

Watson's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Anyone who connected their account can remove Watson's access at any time in their Google Account settings. Watson loses access immediately.
